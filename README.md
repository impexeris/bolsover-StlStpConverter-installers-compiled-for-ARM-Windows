# bolsover-StlStpConverter-installers-compiled-for-ARM-Windows
sources compiled for ARM Windows (separately standalone and Alibre addon installer)
License: BSD-4-Clause
This compile is for Alibre Expert v28 which runs on Windows 11 Parallels virtual machine (hosted on Mac mini M4)
Therefore it might or might not work in other combinations but I believe it should

Two installers - one for standalone converter and one for the Alibre plugin. They can be installed/uninstalled independently
